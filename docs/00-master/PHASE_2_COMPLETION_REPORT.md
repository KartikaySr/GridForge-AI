Date: 2026-09-22. Local durable state, deterministic simulator and live telemetry only.
All measurements are synthetic; no physical actuation or operational authority.

five-asset generation; validation, canonical kW, UTC and quality flags; atomic ingestion/outbox;
bounded admission and counters; authenticated SSE; native reconnect; quality-aware dashboard;

## 4. Migrations

Edge 0001 creates identity, telemetry, latest pointers, transactional outbox and counters,
indexes/constraints. PRAGMA user_version=1 records application; unknown versions fail startup.
Development data stays in .local/edge.db across restart. Central PostgreSQL SQL is unchanged.

## 5. API contracts

Authenticated telemetry batches/state/history/events/SSE and simulator scenario routes under
/api/v1. Body/batch/cursor/page limits and structured errors are generated from Pydantic/OpenAPI.
Native history/scenario IPC is narrow; the webview receives no bearer credential or arbitrary URL.

## 6. Events

TelemetryReceived v1 wraps each normalized point with scope, event ID, source/time and
correlation/causation/idempotency IDs. It commits with the point to the outbox. SSE publishes
complete current-state snapshots, with durable row cursor. Reconnect resets state; lossless
sample retrieval uses ordered events/history. Cloud upload/ACK is deferred.

## 7. Tests created and extended

Python: determinism, normalization, WAL/reopen, atomic outbox, replay conflicts, scope rollback,
late/future/bad/stale/outlier quality, nine malformed variants, capacity rollback, unknown schema,
queue saturation/recovery, disconnect state, API validation/pagination and database failure.
Real-process SSE reconnect; native actual-sample reception and durable identity after restart;
UI aggregate suppression for bad/stale/disconnected values and honest browser preview.

## 9. Results

All 60 tests passed: 44 Python, 13 frontend and 3 native. Formatting, lint, strict TS/Python

Loopback tests need network sandbox permission. Hosted CI has not run: no Git metadata/remote.

(wait over five seconds), disconnected, spike and normal. Confirm invalid data suppresses the
total. Filter an asset, browse older measurements, return to live. Restart from System Health;

## 11. Screens inspected

Native Telemetry dashboard, quality cards, paginated explorer and System Health. Actual native

## 12. Known limitations

Five-asset/one-metric simulation fixture; UTC facility timezone; no registry/RBAC/OT/cloud/
forecast/dispatch/finance. Store caps at 250,000 points (~13.9 hours at five/sec from empty).
Full capacity rejects visibly and preserves unsynced data. Queue submissions are unacknowledged
until commit. Run one runtime per store. Long-duration soak, ownership locking, retention/ACK,
encryption, installer data paths and signed portable packaging remain later work.

## 13. Mocks and fixtures

Seed 57, synthetic asset labels and illustrative power profiles. No real plant measurements,
safety bounds, tariffs or savings. UI tests mock the bridge; repository/process/native tests
use real SQLite, Python runtime and SSE. The legacy Phase 0 scaffold remains separate/unmounted.

## 14. Technical debt

Complete snapshots favor simplicity over deltas; worker/database operations are synchronous at
prototype scale. Commissioned retention, audited configuration, fuller events, durable cloud
ACK, sustained-load qualification and user/connector authorization remain later work. A temporary
QA .app launched via LaunchServices timed out; terminal launch worked. The QA wrapper is not a
supported installer or distributed artifact; packaging remains Phase 10.

## 15. Security and safety

Native-owned token; authenticated loopback HTTP; browser Origin denied; server-fixed generated
scope; replay conflict detection; finite/unit/source checks; bounded requests/queues; restricted
IPC; no generic native HTTP or OT commands. Malformed values are not echoed. Bad/stale/offline
samples cannot become live totals. Operational readiness remains false. DB errors cannot ACK
successful ingestion. Synthetic diagnostic telemetry is intentional; credentials stay private.

## 16. Performance

Local macOS ARM64 benchmark: 5,000 points + outbox in 0.795 s (~6,292 points/sec); 100 state/history
queries averaged 3.238 ms. Store+WAL during the run: 15,331,600 bytes. Development measurements,
not industrial capacity guarantees. Runtime emits five points near 1 Hz. Bounds: eight queued
batches, 100 recent points, 50 native history rows, 256 KiB SSE line, 250,000 durable points.
